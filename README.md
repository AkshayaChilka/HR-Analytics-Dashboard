# HR Analysis Dashboard

## Project Overview
This project focuses on analyzing employee workforce data using Excel and Power BI to understand workforce trends, employee distribution, attrition behavior, job roles, departmental performance, and overall HR metrics. The dashboard provides interactive insights to support HR decision-making and workforce management.

The project includes:
- Data Cleaning & Preparation
- HR Data Analysis
- Employee Attrition Analysis
- Workforce Insights
- Interactive Power BI Dashboard

---

# Business Problem
Organizations need effective workforce analysis to improve employee retention, monitor attrition trends, and understand employee demographics. This project helps HR teams identify:
- Employee attrition patterns
- Department-wise workforce distribution
- Job role trends
- Employee satisfaction indicators
- Workforce diversity insights
